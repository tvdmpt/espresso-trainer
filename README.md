# Espresso Trainer — Telegram Mini App

Мобильный тренажёр настройки дозировки и времени пролива эспрессо. Логика полностью детерминирована на клиенте; история и постоянное хранилище не используются.

## Требования

- Node.js 20.19+ или 22.12+ (рекомендуется актуальная LTS)
- npm

## Установка и локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite из терминала (обычно `http://localhost:5173`). Для проверки логики: `npm test`. Для production-сборки: `npm run build`; результат появится в `dist/`. Проверить production-сборку локально: `npm run preview`.

## Проверка на телефоне / в Telegram

Telegram Mini Apps должны открываться по HTTPS. Чтобы проверить на телефоне до публикации, используйте HTTPS-туннель к dev-серверу (например, Cloudflare Tunnel или ngrok), затем откройте выданный HTTPS URL в браузере телефона. Не публикуйте локальный сервер без необходимости. В обычном браузере приложение тоже работает; если Telegram SDK недоступен, используется встроенная тема по умолчанию и ручной переключатель светлой/тёмной темы.

## Публикация на HTTPS-хостинге

1. Создайте Git-репозиторий и загрузите проект без `node_modules`.
2. В выбранном статическом хостинге (например, Vercel, Netlify или Cloudflare Pages) импортируйте репозиторий.
3. Команда сборки: `npm run build`. Каталог публикации: `dist`.
4. Дождитесь HTTPS-адреса и откройте его на телефоне. Приложение не требует backend или переменных окружения.

## Подключение к Telegram

1. В Telegram откройте официальный аккаунт **@BotFather** и выполните `/newbot`. Следуйте его подсказкам, задайте имя и username бота. Токен храните в секрете — этот проект не использует и не содержит токен.
2. Чтобы добавить кнопку приложения в профиль бота, откройте @BotFather → `/mybots` → выберите бота → **Bot Settings → Configure Mini App → Enable Mini App** и укажите HTTPS URL. Чтобы открыть приложение через кнопку меню чата, используйте `/setmenubutton` и укажите URL приложения. Названия пунктов могут немного отличаться в текущем интерфейсе BotFather.
3. Для актуального интерфейса и способов запуска сверяйтесь с официальной документацией: https://core.telegram.org/bots/webapps и инструкциями BotFather: https://core.telegram.org/bots/features#botfather.
4. Откройте бота на телефоне и запустите Mini App через настроенную кнопку/профиль бота. Проверьте ввод значений, проверку, переключение темы и повторную проверку.

Приложение подключает официальный Telegram Web Apps SDK через скрипт в `index.html`, вызывает `ready()` и `expand()`, реагирует на `themeChanged` и учитывает safe-area inset. Клиентские данные проверки хранятся только в состоянии React и не записываются в `localStorage`, IndexedDB или backend.

## Правила диагностики

- Доза проверяется без округления введённого значения; допустимый диапазон 15,8–16,2 г включительно, поэтому 15,79 и 16,21 остаются вне допуска.
- Сначала исправляется доза. Пока она вне допуска, время пролива не меняет рекомендацию.
- При корректной дозе время менее 20 сек ведёт к Fine (мельче), более 25 сек — к Grosso (крупнее); 20–25 сек включительно — целевой диапазон.
- Поля принимают десятичную точку или запятую; отрицательные числа, пустые значения и некорректный текст отклоняются.
